# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do **not** open a public GitHub issue.

Instead, contact the maintainers privately with:

- A description of the issue and impact
- Steps to reproduce (proof-of-concept if available)
- Any relevant logs/screenshots (redact tokens and personal data)

## Sensitive information

- Never commit secrets such as `.env`, API keys, tokens, or private keys.
- If you suspect a secret was committed, rotate it immediately and remove it from git history before making the repository public.
