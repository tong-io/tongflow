# Sponsors / 赞助

> English below · 中文在前

TongFlow is open-source under [AGPL-3.0](LICENSE) and built in the open.
Sponsorship helps fund ongoing development, maintenance, and community support.

## 中文

### 赞助 ≠ 商业授权(请先读这一段)

赞助是一种**支持与合作**关系,**不改变软件的许可证**。无论赞助多少,使用 TongFlow
仍然受 [AGPL-3.0](LICENSE) 约束。

- 如果你**合规使用**(遵守 AGPL,或仅在内部使用)且希望支持项目、获得品牌曝光
  —— **赞助**适合你。
- 如果你需要在**闭源 / SaaS** 产品中使用 TongFlow 而**不公开源码**,你需要的是
  **[商业授权](COMMERCIAL-LICENSE.md)**,而不是赞助。赞助不会赋予你免除 AGPL
  义务的权利。

### 赞助能得到什么

| 权益 | 说明 |
|---|---|
| 品牌露出 | 在 README / 官网 Sponsors 区块展示 logo 与链接 |
| 鸣谢 | 在发布说明 / 社区渠道致谢 |
| 优先反馈 | issue / 讨论中的优先回应(非合同 SLA) |
| 路线图沟通 | 就需求与优先级与维护者交流的渠道 |

> 注:赞助权益均为**社区性质**,不含合同化的技术支持或服务等级(SLA)。
> 需要合同化平台支持,请走 [商业授权](COMMERCIAL-LICENSE.md)。

### 如何赞助

- **GitHub Sponsors**:见仓库右侧 "Sponsor" 按钮(分档与金额在 GitHub Sponsors 页面)。
- **企业赞助 / 定制合作**:来函 **business@tongflow.com** 洽谈。

## English

### Sponsorship ≠ Commercial License (read this first)

Sponsorship is a **support and goodwill** relationship. It **does not change the
software's license**. No matter how much you sponsor, your use of TongFlow remains
governed by [AGPL-3.0](LICENSE).

- If you **use TongFlow in compliance** with the AGPL (or only internally) and want
  to support the project and gain visibility — **sponsorship** is for you.
- If you need to use TongFlow in a **closed-source / SaaS** product **without**
  disclosing your source, you need a **[Commercial License](COMMERCIAL-LICENSE.md)**,
  not sponsorship. Sponsorship grants no relief from AGPL obligations.

### What sponsors get

| Benefit | Details |
|---|---|
| Brand visibility | Logo + link in the README / website Sponsors section |
| Recognition | Acknowledgement in release notes / community channels |
| Priority feedback | Prioritized responses on issues / discussions (not a contractual SLA) |
| Roadmap input | A channel to discuss needs and priorities with the maintainers |

> Note: sponsor benefits are **community-level** and do not include contractual
> support or service-level agreements (SLAs). For contractual platform support, use
> the [Commercial License](COMMERCIAL-LICENSE.md).

### How to sponsor

- **GitHub Sponsors**: use the "Sponsor" button on the repository (tiers and amounts
  live on the GitHub Sponsors page).
- **Corporate sponsorship / custom partnership**: contact **business@tongflow.com**.
